## Visual Summary

### Landing - Desktop 1280px

- **Hero zone**: div with `linear-gradient(180deg, rgba(15,93,75,0.07) 0%, transparent 100%)`, border-bottom and border-radius 20px. Hero-copy is no longer a floating card - removed border, shadow and background.
- **Left column**: overline "Operations Console - source=api" (subtle monospace tag), h1 "Surplus commodity trading, end to end." (editorial, short), lead, 3 buttons: Sign in / View live auction / API reference.
- **Right column**: Static `StatusPanel` - panel with header "Platform Status" + tag "Demo snapshot", 2 stats (Active Lots: 6 in accent green, Volume: 2,020 kg), 3 recent activity items with colored dot. Hardcoded data, clearly marked as demo snapshot (not live).
- **Workspaces section**: overline label "Workspaces" + "3 roles - cookie-based auth" on the right. Grid of 3 cards with:
  - 3px colored bar at top (Buyer=accent green, Seller=gold, Admin=muted gray)
  - 28x28 SVG icon with role-soft background
  - h3 sans 0.93rem bold (no serif)
  - Muted description, 0.82rem
  - Stats chips in monospace (source=api, 6 active lots, etc.)
  - Primary sm button + ghost sm button
  - Border-radius: 12px (reduced from 28px)

### Landing - Mobile 375px

- `hero-zone` padding 20x16, border-radius 10px, margin-bottom 16px
- Hero collapses to 1 column (status panel goes below content)
- Handoff-grid collapses to 1 column
- Card action buttons keep `width: auto` (not full-width)

### Login - Desktop 1280px

- **Removed** the split structure (left login-copy + right form)
- **Single centered card**, max-width 400px, vertically centered in viewport
- **Card header**: eyebrow "Bio Loop", h2 serif "Sign in", muted subtitle
- **Segmented control** (role-tabs): 3 tabs buyer / seller / admin on soft gray background (rgba 6%); active tab has white bg, shadow-xs, and role color (green / gold / muted) via inline style
- **Form card**: border, shadow and panel bg, radius 12px - Email field + Password field + "Sign in as [persona]" full-width button
- **Skip link** below card: "Skip - open [persona] workspace"

### Login - Mobile 375px

- `login-center` max-width becomes 100% (breakpoint 960px)
- `login-form-card` radius reduces to 10px (breakpoint 640px)
- Segmented control stays in 3 columns
