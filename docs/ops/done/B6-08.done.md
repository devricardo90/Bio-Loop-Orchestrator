# B6-08 - Design layer minimo reutilizavel

## Status

DONE

## Objetivo

Consolidar um layer reutilizavel a partir dos padroes visuais maduros emergentes dos slices B6-04 a B6-09, sem redesign amplo nem mudanca de comportamento funcional.

## Superficies afetadas

- `apps/web/app/globals.css`

## Fora de escopo preservado

- nenhum valor visual foi alterado
- nenhum componente foi refatorado
- buyer, seller, admin, pickup, API e runtime sem toque

## O que foi entregue

### Layer de documentação inline em globals.css

- cabecalho `BIO-LOOP DESIGN LAYER — B6-08` adicionado como bloco comentado antes de `:root`
- documentacao de tokens primarios com intencao semantica:
  - `--accent` forest green: acao, confirmacao, live, CTA primario
  - `--gold` amber: atencao, pendente, agendado, seller highlight
  - `--text`, `--muted`, `--bg`, `--panel`, `--border`, `--shadow`, `--accent-soft`
  - `--radius` 1rem como base; 28px como extensao em cards
- paleta de status documentada: live/awarded/approved/resolved → accent | pending/scheduled/open → gold | ended/rejected/suspe... → muted
- paleta workspace-state documentada: loading/error/empty com semantica de cor
- catalogo de superficies reutilizaveis: .panel, .auction-card, .seller-card, .pickup-action-card, .compact-row, .journey-step, .status-badge, .chip
- tipografia documentada: serif (Georgia) para headings, sans (Trebuchet MS) para body
- animacao @keyframes rise documentada

### Tokens em :root organizados com agrupamentos comentados

- Cores base agrupadas com comentario
- Acento primario (green) separado com comentario semantico
- Acento secundario (gold) separado
- Estrutura (border, shadow) separada
- Tokens shadcn (HSL) com aviso de nao remover

## Por que este layer e minimo e nao um design system

- nao foram criados novos arquivos de tokens
- nao foram criados componentes novos
- nao foram alterados valores existentes
- apenas a documentacao e a organizacao interna do arquivo existente foram adicionadas
- o objetivo e rastreabilidade e base para futuro redesign guiado por Figma, nao padronizacao prematura
