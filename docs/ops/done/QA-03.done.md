## Runbook UAT

### 1. Subir a stack local
```bash
Copy-Item .env.example .env
pnpm install
pnpm compose:up
pnpm --filter @bio-loop/api prisma:generate
pnpm --filter @bio-loop/api db:seed
pnpm dev
```

### 2. Validar runtime
- API health: `http://localhost:4000/health`
- API readiness: `http://localhost:4000/readiness`
- OpenAPI JSON: `http://localhost:4000/openapi.json`
- Scalar UI: `http://localhost:4000/reference`
- Web app: `http://localhost:3000`

### 3. Buyer
- Fazer login como buyer.
- Abrir feed e confirmar listagem de leiloes.
- Abrir um auction.
- Enviar bid e confirmar atualizacao de estado.

### 4. Seller
- Fazer login como seller.
- Abrir lots e results.
- Abrir billing/reports.
- Confirmar que os dados de demo sao carregados da API seedada.

### 5. Admin
- Fazer login como admin.
- Abrir buyers.
- Abrir disputes.
- Confirmar aprovacao/consulta coerente com a API real.

### 6. Pickup/POD
- Abrir pedido elegivel.
- Agendar pickup.
- Registrar POD.
- Verificar o estado final do fluxo.

### 7. Docs/Reference
- Abrir `/reference`.
- Confirmar que auth, trade, pickup, billing e admin aparecem na spec.
- Validar que a documentacao corresponde aos endpoints reais expostos pela API.
