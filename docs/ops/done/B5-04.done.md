## Decisao

Escolhida: configurar Web e API sob dominio same-site controlado, mantendo servicos separados.

Configuracao recomendada:

- Web em `https://app.<dominio-controlado>` ou `https://<dominio-controlado>`
- API em `https://api.<dominio-controlado>`
- `COOKIE_SECURE=true`
- `COOKIE_SAMESITE=Lax`
- `COOKIE_DOMAIN` vazio/host-only inicialmente
- `ALLOWED_ORIGINS` restrito a URL final da Web

Rejeitadas:

- manter Vercel/Railway como dominios cross-site e depender de third-party cookies
- proxy/BFF como proximo passo
- remover CSRF ou redesenhar auth
